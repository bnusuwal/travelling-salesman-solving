How Simulated Annealing Works

1
Start with random tour

Visit all cities in random order, return to start

2
Calculate total tour distance

Sum of all edges including return trip

3
Make a small change

Swap two cities in the route (keep start fixed)

4
Decision rule

Shorter tour -> Always accept

Longer tour -> Accept with probability e^(-increase/exploration)

5
Reduce exploration

Slowly decrease exploration level over time

6
Repeat until optimized

Continue until exploration reaches minimum

Classic TSP Definition

The Problem: "Given a list of cities and distances between them, what is the shortest possible route that visits each city exactly once and returns to the starting city?"

The salesman starts at a city, visits all other cities once, and returns to the start - forming a complete loop.

Tour Distance Calculation

Total = Sum(distance[i][i+1]) + distance[last][first]

Includes the return trip to starting city
